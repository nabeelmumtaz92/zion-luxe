# Zion Luxe

- `site/` — public Phase 1 landing page + lead-capture form (static; see `site/README.md`, `site/TRAFFIC_PLAN.md`).
- `zion.html`, `scraper-worker.js`, `leads.json` — internal lead dashboard and lead engine (being reworked).
- Planned: itinerary draft maker (runs on the Mac) that turns each real lead into a draft itinerary.

## Running it (Mac)
`node server.js` → http://localhost:8787 (inquiries dashboard). The site form posts to `/api/lead` (set `FORM_ENDPOINTS` in `site/script.js`);
each submission is stored in `data/inquiries.json` (git-ignored) and a draft itinerary is generated by `itinerary/` (Claude first, then free-tier AIs).
